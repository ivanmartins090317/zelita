# docs/implementation — entregas feitas

Histórico do que **já foi implementado** (changelog operacional por etapa/feature).

Não é o git log: é o resumo legível para humanos e agentes (o quê, por quê, arquivos-chave, Done).

## Convenção de arquivo

```text
docs/implementation/YYYY-MM-DD-<slug>.md
```

Ex.: `2026-08-12-scaffold-monorepo.md`

## Conteúdo mínimo

- Spec de origem
- O que entrou / o que ficou de fora
- Comandos Done executados
- Arquivos principais
- Riscos remanescentes
- Link para `docs/state` se houver pendência residual

## Quando gravar

Ao declarar **Done** de uma Spec (ou ao fechar um bug relevante com mudança de código).
