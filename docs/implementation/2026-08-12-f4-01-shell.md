## Reflexão

O shell concentra navegação, copy e contexto de conta num módulo `accounts/presentation/family/` com copy externalizada em `content/family.ts`. Funções puras (`computeTrialDisplay`, `resolveNavAreaFromPath`) ficam testáveis sem React. O layout RSC carrega dados uma vez por request; interação mínima no client (modal trocar, drawer mobile). Escalar para F4.2+ exige só trocar placeholders por views reais sem mexer no invólucro.

Risco mitigado: erro no shell afeta 11 rotas — mapa de nav coberto por Vitest; placeholders honestos evitam regressão de expectativa.
